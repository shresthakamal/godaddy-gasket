# GoDaddy Gasket

## Active Version 3.x

_See [what is new]!
If you are looking for previous version docs, see the [LTS branch].
See the [Releases Guide] for more information on active versions._

---

Gasket is a framework maker. **GoDaddy Gasket** is our framework for building
apps at GoDaddy. These plugins and presets will help you quickly create a
NodeJS + React web apps that have [GoDaddy System Integrations]. You will get
server-side rendering, Redux, UXCore2, SSO, routing, PostCSS, bundling, and more
right out of the box. For a description of all the technologies, see the
[Tech Stack] document.

If this is your first time using Gasket, view the [Quick Start Guide] to get up
and running.
