What is Gasket?

Gasket is a framework maker, and we use to align development practices for our Node-based APIs and Web Apps here at GoDaddy. The GoDaddy Gasket plugins and presets will help you quickly create a NodeJS + React web apps that integrate with core GoDaddy systems. You will get server-side rendering, Redux, UXCore2, SSO, routing, SASS, bundling, and more right out of the box.

How it works

This site will be focused on using our private GoDaddy-specific Gasket plugins. For now see the repo docs.

Much of Gasket is also open-sourced and you can more learn more about it and the public plugins available, at gasket.dev.
