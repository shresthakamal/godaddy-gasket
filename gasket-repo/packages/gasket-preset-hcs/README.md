# @godaddy/gasket-preset-hcs

Default set of plugins and config for Header Content Services.
Refer to the [Quick Start Guide] for more details on how to create a new app.

## Usage

For all new Header Content Services, use the create command as:

### npx

```sh
npx create-gasket-app [app-name] --presets @godaddy/gasket-preset-hcs
```

### npm

```sh
npm init gasket-app [app-name] -- --presets @godaddy/gasket-preset-hcs
```

### Yarn

```sh
yarn create gasket-app [app-name] --presets @godaddy/gasket-preset-hcs
```

Replace `[app-name]` with the name of your HCS.

[Quick Start Guide]: https://github.com/gdcorp-uxp/gasket/blob/main/docs/quick-start.md
