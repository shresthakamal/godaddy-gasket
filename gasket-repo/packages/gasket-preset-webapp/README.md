# @godaddy/gasket-preset-webapp

Default set of plugins and config for GoDaddy Gasket WebApps.
Refer to the [Quick Start Guide] for more details on how to create a new app.

## Usage

For all new apps, use the create command as:

### npx

```sh
npx create-gasket-app [app-name] --presets @godaddy/gasket-preset-webapp
```

### npm

```sh
npm init gasket-app [app-name] -- --presets @godaddy/gasket-preset-webapp
```

### Yarn

```sh
yarn create gasket-app [app-name] --presets @godaddy/gasket-preset-webapp
```

Replace `[app-name]` with the name of your application.

[Quick Start Guide]: https://github.com/gdcorp-uxp/gasket/blob/main/docs/quick-start.md
